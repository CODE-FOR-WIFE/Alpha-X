# Template Research — AlphaX Revamp (2026-08-24)

> เกณฑ์คัด: dark cinematic luxury · serif editorial · มี pattern สำหรับ content hub (magazine) ·
> โครงยุบเหลือ 5 หน้าได้ · เอามาต่อเป็น Next.js ได้ (stack ที่ pitch)

## ข้อคิดก่อนซื้อ (สำคัญกว่าตัว template)

1. **เราซื้อ template เพื่อเอา "layout DNA"** — จังหวะ section, hero pattern, spacing, interaction
   ไม่ใช่เอาโค้ด เพราะ demo/งานจริงเป็น Next.js + tokens ของเราเอง
2. **Webflow templates ($79) design quality สูงสุดในตลาด** — live preview เห็น interaction จริง
   โค้ด export มาใช้ตรง ๆ ไม่ได้ แต่แกะ structure ง่าย → เหมาะเป็น design base ที่สุด
3. **ThemeForest HTML templates ($17–25)** — ยกโค้ดมาแปลงเข้า Next.js ได้จริง แต่คุณภาพ design
   เฉลี่ยต่ำกว่า ต้อง vet หนัก ๆ กันหน้าตา template-slop
4. **Elementor/WordPress kits — ไม่ซื้อ** ต่อให้สวย (ติด WordPress ทั้ง stack) ใช้ดู reference ฟรีจาก preview พอ

## แผนที่ช้อประดับ Section (ตรวจของจริงแล้ว — แนวทาง "ซื้อหลายตัว หยิบคนละส่วน")

### Kenslow (ตรวจ preview จริงทั้งหน้าแล้ว ✓)
โทนจริง: **สว่าง + น้ำเงิน corporate** ไม่ใช่ dark — แต่**โครง section ระดับดี** และเราจะทับด้วย tokens (ดำ/แดง/ทอง + ฟอนต์ ALPHA X) อยู่แล้ว → ซื้อเพื่อเอาโครง ไม่ใช่เอาผิว
สิ่งที่หยิบใช้ได้ / map เข้าเว็บเรา:
- Hero split + **3 stat blocks** ($500M AUM / 95% retention / 30 yrs) → **Home**: พอร์ต 20,000 ลบ. / RM ดูแลรายคน / เครือ SCBX
- **Services 4 การ์ดรูป+overlay+arrow** → **Products**: 5 solutions (Car/Yacht/Aircraft/Property/Gold)
- **Trust section** (พื้นเข้ม + serif "Integrity & excellence" + stat callouts) → **About**: โครงหน้า Trust แทบยกมาได้เลย
- **Case studies timeline แนวนอน** (2025/2024/2023) → **About**: company milestones
- Blog featured 2-up → **Home**: What's Trending
- ส่วนที่ทิ้ง: icon cards 4 คอลัมน์เท่ากัน (pattern ซ้ำ = slop), วงรี decoration น้ำเงิน

### ช่องที่ Kenslow ไม่ตอบ → ต้องได้จากธีมที่สอง (สาย hotel/editorial ที่ dark กว่า)
- **Home hero แบบ dark cinematic เต็มจอ** (Kenslow เป็น split สว่าง) → ดู Moonlight / Gregori / Niraya
- **Club hub magazine layout** (blog ของ Kenslow เรียบเกิน) → ดู Art Gallery 128 ($79 — high-end จริง) / editorial templates
- ตัวเลือกสาย hotel ที่ควรเปิด preview เทียบ: **Gregori** (advanced interactions) · **Moonlight** (immersive) · **Wake** ($49 minimal) · [Webflow hotel list](https://webflow.com/list/hotel)

### สูตรผสมที่แนะนำ (ซื้อ 2 ตัว)
1. **Kenslow** — โครงหน้า trust/finance: About + Products + stats ≈ $49–79
2. **ธีม hotel/editorial dark 1 ตัว** (Gregori หรือ Moonlight หรือ Art Gallery 128) — hero cinematic + Club hub magazine
ตัวเชื่อมทุกอย่างคือ **tokens ของเรา** (ดำ #0B0B0D + แดง #E4002D + ฟอนต์ ALPHA X + serif) → ผลลัพธ์ไม่มีทางเหมือน template ต้นทาง

## คำแนะนำ

**ทางที่แนะนำ:** ซื้อ **Webflow 1 ตัวจากสาย finance (Kenslow หรือ Koch)** เป็นโครงหลัก
+ เก็บ reference ฟรีจาก preview ของสาย hotel/yacht มาเสริม mood ส่วน Club hub
เหตุผล: ได้ความหรูระดับที่ผ่านเกณฑ์ anti-AI-slop เร็วสุด และแบรนด์เราแข็งอยู่แล้ว (ฟอนต์จริง+สีจริง+tokens) — template เป็นแค่โครง

**ก่อนกดซื้อ:** ส่งลิงก์ preview ตัวที่เล็งมาให้ vet ก่อน — เช็คกับเกณฑ์: จังหวะ section ไม่ซ้ำ, serif+tracking, ไม่ card-grid ซ้ำซาก, มี editorial/blog layout ที่สวยพอเป็น Club hub
